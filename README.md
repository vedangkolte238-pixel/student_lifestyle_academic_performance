Student Lifestyle & Academic Performance Analysis

About the Project

This project analyzes student lifestyle and academic performance using Python.

The dataset contains information about students such as study hours, sleep hours, screen time, attendance, social time, previous academic scores, and current academic scores.

The main purpose of this project is to understand the relationship between different lifestyle factors and academic performance.

Dataset

I created the dataset for this project for academic analysis.

The dataset contains:

- 100 students
- 10 columns
- Numerical and categorical variables
